# Checkpoint — المحاسبة + الحج والعمرة + التعاقدات والمخزون

## الهدف
تثبيت نقطة نظيفة ومختبرة قبل بدء جولة تبسيط العملاء والموردين والفواتير وباقي الأقسام.

## المحاسبة
- القيد المزدوج، الأستاذ، الميزان والقوائم الأساسية.
- تسويات الموردين والعملاء ورسوم الإلغاء والاسترداد الجزئي.
- إيرادات وتكاليف مؤجلة/مستحقة مرتبطة بتاريخ تنفيذ الخدمة.
- أصول وإهلاك، قروض وفوائد، مخصصات، ديون مشكوك فيها، رواتب وأرصدة افتتاحية.
- موازنات ومطابقة بنكية وتدفقات نقدية محسنة.
- مراكز تكلفة وربط برنامج الحج/العمرة بالمحاسبة المركزية.

## الحج والعمرة
- البرنامج يُنشأ Draft/Planning ولا يُفتح للبيع تلقائيًا.
- Program Workspace يوضح الجاهزية والخطوة التالية والمالية والمخزون.
- مكونات الباقة تحدد الخدمات المطلوبة فعليًا بدل افتراضات ثابتة.
- توزيع غرف مرن ومتعدد الأنواع على مستوى كل إقامة.
- دورة الحجز والمسافرين والتأشيرات والغرف والنقل والإلغاء مرتبطة بنفس الـCore.

## التعاقدات والمخزون
- الفندق: مخزون يومي وأسعار/سعات موسمية ومنع Overbooking.
- الطيران: الاستخدام الفعلي يُجمع عبر كل البرامج المرتبطة بنفس البلوك.
- النقل: السعة تُحسب حسب تداخل الفترات، لا كمجموع تاريخي مضلل.
- التأشيرات: حصص وتواريخ وتكلفة وRelease/Stop Sale.
- خدمات تعاقدية إضافية: مخيمات، إعاشة، زيارات، مرشدون، روضة، تأمين وغيرها.
- Partial allocation adjustment وContract amendments.

## الخدمات السياحية
- الوضع الافتراضي: البحث في مخزون الشركة أولًا.
- عند وجود مخزون مناسب تُسحب التكلفة من العقد ويُحجز المخزون.
- لا تُنشأ فاتورة مورد جديدة عند بيع مخزون سبق التعاقد/الشراء عليه.
- عند عدم وجود مخزون مناسب يمكن الانتقال للشراء الخارجي.

## حملة النظافة
- فصل منطق الغرف في Module مستقل بدل تضخيم operations.ts.
- فصل منطق مخزون الخدمات المباشرة في Module مستقل.
- إزالة أرقام الإصدارات القديمة الثابتة من اختبارات الجودة وربطها بالإصدار الحالي.
- توحيد رقم الإصدار في Runtime / Web / Server / Android / Mobile.
- نقل تقارير QA التاريخية إلى docs/history/qa.
- عدم حذف وظائف النسخ الاحتياطي أو ملفات Android/PWA أو اختبارات Regression لأنها مكونات تشغيل/حماية وليست مخلفات.

## حالة الاختبارات
يتم اعتماد هذا الـCheckpoint فقط بعد نجاح Build وRegression النهائيين في بيئة العمل الحالية.
