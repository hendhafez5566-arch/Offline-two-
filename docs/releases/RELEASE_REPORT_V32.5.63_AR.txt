Elhafez Tourism Offline v32.5.63

نطاق الإصدار: إعادة بناء مسار الطباعة وواتساب فقط.

- مصدر المستند الوحيد: printPayload HTML/CSS A4 الحالي.
- مولد PDF الوحيد: Chromium/WebView PrintDocumentAdapter.
- ملف PDF الناتج يحتفظ بالنص القابل للتحديد وبـ RTL وCSS وتقسيم الصفحات.
- زر الطباعة يطبع ملف الـPDF الناتج نفسه عبر PdfFilePrintAdapter.
- زر واتساب يرسل ملف الـPDF الناتج نفسه إلى الرقم المسجل عند دعم واتساب لذلك.
- يمكن إعادة استخدام نفس ملف PDF byte-for-byte بين الطباعة وواتساب طالما محتوى المستند لم يتغير.
- حذف مسارات Canvas / Bitmap / PrintedPdfDocument / Structured PDF القديمة من الكود النشط.
- حذف اختبارات الطباعة التاريخية المتعارضة واستبدالها ببوابة واحدة للسلوك النهائي.
- لا تعديلات على accounting أو finance أو قاعدة البيانات أو الحجوزات أو المخزون.
