# Elhafez Tourism — Full Offline Copy v32.5.48

نسخة مستقلة كاملة تعمل محليًا على Android بدون Railway أو PostgreSQL أثناء التشغيل.

- نفس وظائف النظام الأساسية: العملاء، الموردون، المندوبون، الخدمات، الحجوزات، الحج والعمرة، المحاسبة والتقارير.
- البيانات والمرفقات تحفظ على الجهاز نفسه (IndexedDB / Local WebView storage).
- الطرف الواحد يمكن أن يحمل أدوار عميل/مورد/مندوب مع فصل الذمم محاسبيًا ومقاصة رسمية فقط عند الاعتماد.
- المطبوعات تستخدم تنسيقًا مختصرًا موحدًا، وPDF واتساب يُولد A4 متعدد الصفحات مباشرة من محرك Chromium للطباعة بدون Screenshot للمستند الكامل.
- «اختصاراتي» تحفظ لكل مستخدم حتى 12 شاشة؛ لا توجد قائمة «آخر استخدام».
- سجل النشاط يعرض حتى 1000 حركة في الواجهة كما هو.
- النسخ الاحتياطي الخارجي والاستعادة المحلية متاحان.
- App ID مستقل: `com.elhafez.tourism.erp.offline` ويمكن تثبيتها بجانب النسخة الأونلاين.
- لا توجد مزامنة أجهزة متعددة ولا Owner Center ولا Railway في Runtime الأوفلاين.
- إزالة التطبيق أو مسح بياناته قد يحذف البيانات المحلية؛ خذ Backup خارجيًا أولًا.
- وظائف الإنترنت الطبيعية مثل WhatsApp تحتاج اتصالًا وقت استخدامها فقط.

## بناء APK من GitHub
1. ارفع النسخة إلى Repository مستقلة.
2. افتح Actions → **Elhafez Tourism Offline Android**.
3. شغّل **Run workflow**.
4. نزّل Artifact باسم **Elhafez-Tourism-OFFLINE-v32.5.48**.

لا تحتاج Railway ولا `ELHAFEZ_TECHNOLOGY_URL`.
