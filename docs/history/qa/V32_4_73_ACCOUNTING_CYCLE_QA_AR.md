# تقرير v32.4.73 — اكتمال الدورة المحاسبية

## الإصلاحات

- إلغاء فاتورة مرحّلة ينشئ القيد العكسي ويحفظ المستند للتدقيق، مع إظهار المتبقي صفرًا.
- الفواتير الملغاة لا تدخل في دفتر ضريبة المخرجات أو المدخلات بعد العكس.
- إلغاء فاتورة مورد منشأة من أمر شراء يعيد أمر الشراء إلى حالته السابقة قبل التحويل، بدل بقائه «محوّل» بلا فاتورة صالحة.
- يمكن إصدار فاتورة بديلة من أمر الشراء بعد الإلغاء، مع الاحتفاظ بتاريخ كل الفواتير السابقة وعدم تكرار الرقم الخارجي.
- إلغاء فاتورة منشأة من عرض سعر يعيد عرض السعر إلى «مقبول» لإعادة الفوترة.
- أوامر شراء الحج والعمرة تحتفظ بمعرّف البرنامج ومركز التكلفة عند الإنشاء والتعديل والتحويل إلى فاتورة مورد.
- التزام مورد الحج والعمرة يعود إلى «ملتزم» عند إلغاء فاتورته، مع الاحتفاظ بمرجع الفاتورة الملغاة للمراجعة.
- إصلاح تلقائي مرة واحدة للبيانات القديمة التي بقي فيها أمر شراء «محوّل» بعد إلغاء فاتورته.

## قواعد الحماية المحاسبية

- لا تحذف فاتورة أو قيدًا مرحّلًا؛ يتم الإلغاء والعكس فقط.
- لا تلغى فاتورة عليها تحصيل أو سداد قبل عكس الحركة النقدية.
- لا تلغى فاتورة عليها إشعارات دائنة/مدينة قائمة قبل عكس الإشعارات.
- أمر الشراء المسودة فقط يقبل الحذف النهائي؛ المعتمد أو المستلم يقبل الإلغاء، والمحوّل يعالج من الفاتورة أولًا.
- إغلاق برنامج الحج والعمرة لا يعكس الإيرادات أو التكاليف، بينما الإلغاء قبل السفر يلتزم بموانع التحصيل والتذاكر والتأشيرات وفواتير الموردين.

## الاختبارات

- دورة الفواتير والتحصيل والسداد والدفعات المقدمة والعملات.
- دورة إلغاء وإغلاق برنامج الحج والعمرة.
- ربط البرنامج ومركز التكلفة بأمر الشراء وفاتورة المورد والقيد.
- إلغاء فاتورة المورد ثم إعادة إصدار فاتورة بديلة.
- تصفير المتبقي واستبعاد الضريبة بعد الإلغاء.
- اتزان القيود بعد كل عمليات الإلغاء والعكس.
