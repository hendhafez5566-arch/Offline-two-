# v32.4.85 — Filter Hierarchy + Pull Refresh + Arabic Fonts

## التعديلات
- فصل تبويب نطاق السجل `الحالي / السجل السابق / الكل` بصريًا عن فلاتر الحالة الموجودة تحته؛ نطاق السجل أصبح بلون محايد/داكن مستقل، والفلاتر التشغيلية تحتفظ بألوانها الدلالية.
- منع قص أسماء تبويبات نطاق السجل على الموبايل. الاسم والعدد يترتبان على سطرين داخل كل خيار مع بقاء الثلاثة Fit في صف واحد.
- قواعد Smart Filters نفسها ما زالت موحدة على مستوى النظام؛ بطاقات الحالة على الموبايل تظهر 3 في الصف مع التفاف منظم.
- تحويل مؤشرات لوحة تشغيل الحج والعمرة الأربعة إلى Smart Drill Filters: البرامج المفتوحة تفتح البرامج بفلتر «مفتوح»، حجوزات العمل تفتح الحجوزات بفلتر «قيد العمل»، الحجوزات المؤقتة تفتح فلتر Hold، ومشاكل التشغيل تفتح شاشة المشاكل. آخر اختيار يظل Active عند الرجوع للوحة.
- تقليل حساسية Pull-to-Refresh: المؤشر لا يظهر إلا بعد سحب مقصود (34px)، ولا ينفذ التحديث إلا بعد 92px. الحركة الأفقية أو الرجوع لأعلى تلغي الإيماءة فورًا.
- إصلاح بقاء دائرة التحديث معلقة بعد سحب غير مكتمل أو touchcancel أو تغير موضع الـscroll؛ يتم تنظيف حالة المؤشر في كل مسارات الإلغاء.
- استبدال خيارات الخطوط غير المحمولة على Android بخيارات عربية فعلية: Default، Cairo، Tajawal، Noto Sans Arabic، IBM Plex Sans Arabic، Noto Kufi Arabic. يتم تحميل ملف CSS للخط المختار فقط، مع fallback احترافي لو تعذر التحميل.
- ترحيل الاختيارات القديمة غير المتوفرة غالبًا على Android: System UI → Cairo، Segoe UI → Tajawal، Arial → Noto Sans Arabic.
- تطبيق الخط المختار عبر `--system-font` على النظام بالكامل مع معاينة فورية، والطباعة تستخدم نفس عائلة الخط.
- إعادة تصميم أزرار حجم الخط إلى Grid احترافي: 6 خيارات على الشاشات الواسعة و3 في الصف على الموبايل.
