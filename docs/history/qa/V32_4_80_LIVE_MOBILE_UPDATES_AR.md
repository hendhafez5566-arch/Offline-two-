# v32.4.80 — تحديثات الموبايل بدون APK لكل تعديل

## الهدف
تحويل تطبيق Android إلى **Live Shell** ثابت: التطبيق يفتح واجهة ERP المنشورة على Railway مباشرة، بينما تبقى إمكانات Capacitor الأصلية مثل زر الرجوع والطباعة ومراقبة الشبكة وPull-to-Refresh متاحة.

## النتيجة العملية
- تعديلات ERP العادية في TypeScript / الشاشات / المحاسبة / التقارير / السيرفر: **GitHub → Railway فقط**. لا يلزم Build APK ولا حذف التطبيق ولا إعادة تثبيته.
- إذا كان التطبيق مفتوحًا أثناء نشر إصدار جديد، يفحص `/api/health` ويعيد تحميل الواجهة الجديدة تلقائيًا عندما لا يوجد نموذج غير محفوظ.
- إذا كان هناك نموذج غير محفوظ، لا يعيد التحميل قسرًا ويعرض تنبيهًا للحفظ أولًا.
- GitHub Action الخاص بـAPK أصبح يعمل تلقائيًا فقط عندما تتغير ملفات Android الأصلية أو إعدادات Capacitor، مع بقاء التشغيل اليدوي متاحًا.

## متى نحتاج APK جديدًا؟
فقط عند تغيير جزء Native حقيقي مثل Java/Gradle/صلاحيات Android/إعداد Capacitor أو Plugin أصلي. تغييرات واجهة ERP وBusiness Logic لا تحتاج APK جديدًا بعد تثبيت هذا الإصدار.

## ملاحظة التوقيع
الـDebug APK الذي تنتجه GitHub Actions قد لا يقبل التثبيت فوق Debug APK بُني بمفتاح مختلف. للنشر للعملاء بدون حذف التطبيق يجب اعتماد Release Signing Key ثابت أو Google Play App Signing. هذه خطوة إعداد واحدة وليست مطلوبة مع كل تحديث ويب.

## التوقيع الثابت (مرة واحدة)
الـWorkflow جاهز لاستخدام أربعة GitHub Secrets:
- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

إذا كانت موجودة يبني Signed Release APK يمكن تثبيت الإصدارات التالية فوقه بشرط ثبات المفتاح وزيادة `versionCode`. إذا لم تكن موجودة يبني Debug APK كحل احتياطي مع تحذير واضح.
