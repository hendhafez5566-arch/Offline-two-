# تقرير v32.4.77 — ضبط الحج والعمرة

## النتيجة

تمت مراجعة قسم الحج والعمرة داخل نفس نظام ERP، دون إنشاء نظام منفصل ودون Reset أو Migration لبيانات الشركات.

## الإصلاحات

- تثبيت تنقل القائمة الجانبية؛ زر الوحدة يفتح المسار المطلوب بدل البقاء على لوحة التشغيل أو الرجوع للرئيسية.
- تغييرات حالة البرنامج الحرجة من ملف البرنامج تنتظر تأكيد الخادم قبل إظهار النجاح.
- منع إغلاق البرنامج إذا بقيت حادثة تشغيلية مفتوحة أو مهمة حرجة غير مكتملة.
- الإغلاق يظل تشغيليًا فقط: لا يحذف ولا يعكس الإيرادات أو التكاليف أو القيود التاريخية.
- الإلغاء يمنع عند وجود تحصيل فعلي أو فاتورة مورد أو تذكرة/تأشيرة منفذة حتى تتم التسوية الصحيحة.
- تحسين ترتيب أزرار الإجراءات والجداول والنصوص الصغيرة على شاشة الهاتف.
- رفع الإصدار إلى `32.4.77` لكسر كاش PWA وAndroid وضمان تحميل الواجهة المعدلة.

## التحقق

- دورة حجز كاملة: برنامج، حجز، فاتورة، عربون، مسافرون، غرف ونقل.
- دورة الإلغاء والإغلاق وأوامر الشراء وفواتير الموردين.
- اتزان القيود وعدم وجود أثر مالي من الإغلاق التشغيلي.
- تكامل واجهة الحج والعمرة مع الراوتر والطباعة المركزية.
- بناء الويب والخادم وملفات PWA بنجاح.
