# Elhafez Tourism v32.5.5 — تحسين الأداء للبيانات الكبيرة

هذا الإصدار لا يغيّر دورة العمل أو المحاسبة. التعديل تقني لتحسين القوائم والبحث عند كبر البيانات.

## ما تغير
- Lazy Data Table مركزي: يبني صفوف الصفحة الحالية فقط.
- البحث لا يحتاج تكوين HTML لكل السجلات.
- الفرز والتصدير يحافظان على كل النتائج المطابقة.
- فهرسة أرصدة الفواتير والتخصيصات في مرور واحد بدل إعادة فحص كل السندات لكل فاتورة.

## اختبار الضغط المحلي
- 5,000 عميل
- 2,500 مورد
- 25,000 فاتورة
- 12,500 سند قبض
- 50,000 قيد / 100,000 سطر قيد

النتيجة في بيئة الاختبار: صفحة العملاء ~0.35 ثانية، الموردين ~0.03 ثانية، الفواتير ~0.32 ثانية، مع 25 صفًا فقط ظاهرًا في كل صفحة.
