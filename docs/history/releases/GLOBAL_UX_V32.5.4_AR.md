# Elhafez Tourism v32.5.4 — Global UX Cleanup

- زر التالي في كيبورد الموبايل ينتقل للحقل التالي بدل تنفيذ الحفظ بالخطأ.
- آخر حقل فقط يعرض إجراء "تم"، بينما الملاحظات متعددة الأسطر تحتفظ بزر إدخال سطر جديد.
- مجموعات القائمة الجانبية أصبحت Accordion: فتح مجموعة يغلق المجموعة المفتوحة الأخرى تلقائيًا.
- إزالة أرقام عدد العناصر الملتصقة بعناوين مجموعات القائمة الجانبية.
- سهم فتح/قفل واضح وموحد للمجموعات على الموبايل والويب.
- توحيد إنشاء برنامج الحج/العمرة: أي "برنامج جديد" يفتح المعالج الموجّه، بينما النموذج المباشر مخصص لتعديل برنامج موجود.
