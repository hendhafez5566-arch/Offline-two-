# Elhafez Tourism v32.5.6 — سلامة الإلغاء والتنظيف

- إلغاء برنامج/حجز قبل اعتماد أمر الشراء يحذف مسودة أمر الشراء التلقائية نهائيًا.
- الالتزام الداخلي المرتبط يُلغى ويحتفظ بمرجع رقابي لرقم أمر الشراء المحذوف دون إبقاء رابط يتيم.
- أمر الشراء المعتمد أو المنفذ لا يُحذف؛ يُلغى/يُعكس وفق حالته للحفاظ على الدورة المستندية.
- وجود فاتورة مورد يمنع الحذف الصامت ويُلزم بالتسوية/الإشعار المناسب.
- ترقية البيانات تنظف تلقائيًا مسودات أوامر الشراء القديمة المتروكة بسبب برامج ملغاة عندما لا يوجد تنفيذ أو فاتورة.
- أضيف اختبار Regression ثابت لهذه الدورة على العميل والخادم.
