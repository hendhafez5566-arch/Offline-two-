ERP Professional Suite — Update Only v32.4.15
================================================

هذه الحزمة لتحديث نفس مشروع ERP الحالي من v32.4.13 أو v32.4.14 إلى v32.4.15 دون إنشاء مشروع جديد ودون المساس ببيانات الشركة.

أهم ما يتضمنه التحديث:
- دمج الحج والعمرة والموارد البشرية Native داخل نفس صفحة ERP بدل تشغيلهما كتطبيقين منفصلين داخل iframe.
- إلغاء ملفات التشغيل المستقلة القديمة للعمرة وHR وربطهما بنفس الـRouter والـStore والحفظ المركزي.
- منع رسالة «تم الحفظ» قبل اعتماد الحفظ المركزي فعليًا.
- إصلاح أخطاء HR الحرجة: تفاصيل المأموريات، الشيفت الليلي، الغياب، اختيار موظفي مسير الرواتب حسب الشهر، الإجازات والعقود.
- إصلاح دورة الحج بحيث لا يتم تجاوز المشاعر/المخيم والتصاريح/نسك في برنامج الحج.
- تحسين الحفظ والمعاملات في الحج والعمرة وHR وتقليل الحفظ الزائد أثناء الاستخدام.
- إضافة اختبارات Native Integration وHR Regression وتحديث اختبارات العمرة/الحج والـHardening والـConcurrency.

قاعدة البيانات:
- migrationRequired = false
- لا توجد Migration جديدة في هذا التحديث ولا يتم إنشاء أو حذف جداول.

ملفات قديمة يتم حذفها عمدًا:
- فقط الملفات المدرجة في UPDATE_DELETE_MANIFEST.txt.
- وهي ملفات iframe/Standalone القديمة للحج والعمرة وHR.
- لا يتم حذف أي ملف بيانات أو إعدادات شركة.

الحزمة تحافظ على:
- .env
- Company ID
- الترخيص
- backups
- PostgreSQL data
- Docker volumes
- إعدادات وبيانات الشركة الحالية

طريقة التحديث على Windows/Docker:
1) فك ضغط ZIP بالكامل، ولا تشغل BAT من داخل الملف المضغوط.
2) شغّل INSTALL_UPDATE_WINDOWS.bat.
3) إذا كانت الحزمة في مجلد مستقل سيطلب منك اختيار مجلد ERP الحالي.
4) المثبّت ينشئ PostgreSQL Backup قبل استبدال أي ملف.
5) ينسخ ملفات التحديث فقط ويحذف ملفات iframe القديمة المحددة بالاسم.
6) يعيد Build وتشغيل التطبيق ويفحص /api/health ورقم الإصدار.

طريقة GitHub/Railway:
1) فك الضغط.
2) شغّل PUBLISH_UPDATE_WINDOWS.bat.
3) يتم نسخ ملفات التحديث وحذف ملفات iframe القديمة من الـrepository.
4) يتم تشغيل Verify كامل قبل Commit/Push.
5) لا يتم Push إذا فشلت الاختبارات.

مهم:
هذه Update Only وليست نسخة كاملة. لا تستبدل مجلد المشروع كاملًا بهذه الحزمة يدويًا؛ استخدم المثبّت أو انسخ محتوياتها فوق نفس المشروع مع الحفاظ على الملفات غير الموجودة بالحزمة.
